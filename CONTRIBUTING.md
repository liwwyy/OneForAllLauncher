# Contributing to OneForAllLauncher

OneForAllLauncher is a fork of OneClient by Polyfrost, licensed under GPL-3.0-only.
Preserve LICENSE, ATTRIBUTION.md and original copyright notices.

Follow README.md for building, testing, packaging and syncing upstream.
Keep fork-specific behavior separate from upstream maintenance commits. After
changes, run cargo build and cargo test -p oneclient_auth. Test account creation,
onboarding, startup and the packaged launcher before publishing a release.

Submit issues and pull requests to this fork, rather than to Polyfrost for fork-specific behavior.
